# 轮35：有界邻接短线链

1. 用户失败：轮33整页候选仍0/1；轮34证实近失组合底侧一端43.321px无观察支持，超20.3px角点限制。
2. 定位：事后只读raw追踪发现底侧原拟合末端附近raw113为26.35px短线，已被一跳补招。紧邻它的raw109长度32.6px、相对原支持方向5.42度，但远端距原拟合6.26px，大于4.872px；相邻两段在图上构成轻微弯曲的连续笔画。原函数只查原支持的端点邻域，不沿已观察短段继续找。上述ID只用于评价和定位，不写入生成器。
3. 目标后复读既有学术路线：L-CNN/HAWP提供线段与连接点图的表示依据；本轮是有界邻接图的工程借鉴，不部署或复现其权重。独立导师SKILL未找到，遵循user-centered-optimization。
4. 假设：用最多两条真实邻接短段形成端点短链，可以保留轻微弯曲手绘边缘的观察证据，减少外框缺角拒绝；最终整体拟合和闭合限制仍可能否决，必须保留负结果。
5. 固定机制：每端最长2跳、非无限递归；只用同次raw中未选且短于原12%短边阈值的笔画。每段相对原锚方向8度内、相对前段方向8度内、两端距前段无限直线不超过短边1.2%、间隙不超过短边6%，必须在原锚投影方向继续向外。最多4条额外引用/组。按最终向外伸展、总观察长度、raw ID确定次序，选择一条最强链后整体TLS；所有旧/新端点距最终拟合仍不超过原1.2%，否则保留原组并记录拒绝，不自动换次优链。空隙不计支持，原60%支持、图内凸性、角点外延/内部gap/来源不复用等不变。相邻局部线与全局直线资格不同是本轮改变，明确不是完全相同几何表示预算。两跳可能串入别的控件/桌纹，所有合法候选都需目检。
6. 对照与预算：同一次新LSD、相同空间48长线锚点和原聚合，基线轮33一跳、候选两跳，0 LLM/0深网/无安装，原UV，执行上限120秒；额外源引用预算从最多2G增为4G，G为实际支持组数。不是同观测预算消融。目标正确整页候选从0/1到1/1；所有候选逐张核查、来源真实且每端最多2跳，图外角点0。最终语义选择不运行，记未评而非正确；无HTML/IoU/功能分。002为开发材料，GT不输入，原图ASR不变、原失败保留、同一实施者非独立人工。本轮只验证候选可用性，不冒称完整系统改善。
