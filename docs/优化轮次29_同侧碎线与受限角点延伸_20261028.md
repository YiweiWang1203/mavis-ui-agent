# 轮29：同侧碎线聚合与受限角点延伸

1. 用户失败与假设：用户认可并授权“通过同侧碎线聚合和受限的角点延伸，提高页面外框候选的完整性，同时避免把纸边、桌纹和内部控件拼成假页面”，已发拆解师先入v2为待验假设。轮28单段支持60%导致0候选；这不等于已证明碎片是唯一原因，仍可能方向/去重/线cap/图边截断。
2. 定位：原LSD叠图有四侧线段，但单一原始线无法覆盖目标侧；轮28投影检查防止把不在边上的长段当支持，不应删除这个保护。当前目标是形成正确、可追溯的页面候选，无HTML收益预设。
3. 目标确定后复读空间层级与边界溯源、2010年后技术补充：LSD/OpenCV用于几何线证据；DeepLSD不提供UI身份；MM-WebAgent只借鉴全局/局部分工，不引用为补线算法。以下锚点聚合、TLS拟合和区间并集是本系统工程方案，不冒称某篇现成论文已解决手绘页面。独立同名导师SKILL未找到，遵循user-centered-optimization六步。

## 实施前固定方案

- 输入：002原冻结照片/口述/提示，同轮28图SHA8f4aec60993cfc8ce7aad9eeb3fd2edc1329a35d7efcaf514089cc8a211988a8。重新从原图执行既有LSD和detect_line_candidates，两组共用同一次最多48条原始候选；不读取旧响应、标注或人工四边，不换帧/ASR，不改旧HTML。
- 基线：轮28单段闭合与每侧60%实际投影支持，最多16候选。
- 候选：以每条原线为锚点，同方向且夹角<=8度、两个端点至锚线距离<=短图边1.2%的线才可聚合。沿锚点方向排序，间隔<=短图边6%才属于同支持分量；避免无限传递跨平行框。对端点TLS拟合，所有端点离拟合线仍须<=短图边1.2%；保留每条原始ID、原端点及投影区间，原线对象不变。按观察区间并集长度排序每方向最多24组，记录cap前数。不把两条近平行线的间隙涂掉；适配性仍需逐图核查。
- 闭合：同原compile_boundary的图内、凸性、次序、面积>=2%、基础长度要求；枚举上限C24,2²=76176。四侧实际投影区间并集各>=60%，重叠部分不重复计数，空隙不算观察支持。每端从最近观察支持延至角点的空白<=min(该侧12%,短图边5%)；最长内部空隙<=该侧15%。同一原线不可复用于多个侧。只对外框候选生成拟合几何，内部原始图像/线条不改。允许透视凸四边形，不强制图内直角。
- 排名/语义：沿用面积×最弱侧支持及四角近重复抑制，最多16候选；不将几何排序当答案。两组同一模型、提示、候选ID选择schema、原图及组内全部候选contact sheet；模型只能选候选ID或未决。若空集，两组同样直接未决并跳过模型，不请求模型制造ID；这是对称工程前置，不称空集通过。候选表示/数量改变带来token差异单报。
- 预算：每组最多1次Qwen/Qwen3-VL-8B-Instruct，8192输出token/600秒/零重试，整轮最多2次物理调用；无DeepLSD前向、无下载/安装，使用原my_agent/.venv/bin/python。没有候选可以0次，实际成本分组/物理分别报告，不称相同实际调用数消融。

## 预定验收与否证

主目标：人工逐个检查候选中是否至少1个贴合真实手绘UI外框（正确候选可用1/1），最终页面身份正确1/1、四侧真实来源4/4、角点外延全部限内、图外点0、同源侧复用0；明显纸桌/内部框误选0、选择结果明显裁失UI0。无选择结果不填裁失或IoU，不把未决当通过。所有候选包括未选中/截去cap前数量要记录；候选中存在纸/内部框本身不是最终误选成功率，但其比例和风险需审查。新支持连接了不属于同边的线即负例，不能通过几何分叫语义正确。没有用户确认GT，不计算IoU/召回准确率；本实施者审查不等于独立人工。

4项新增工程测试：观察区间并集不填空/不重复、邻近平行框不合并且原线不变、合成碎边矩形正确闭合、角点延长过大拒绝；加原7项共11通过。工程检查不替代真实单例。若真实页候选仍缺失，先查来源覆盖/拟合/限距/cap，不能当轮调阈值再挑成功。若选成内部框，归到候选/语义层而非直接宣称修好。
