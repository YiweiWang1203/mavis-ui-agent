# 空间层级与边界定位：参考依据及实现溯源

交接日期：2026-10-28。接收对象：任务拆解师。用途：更新优化工作稿v2的研究依据、方法设计和实验讨论，保留冻结稿。本文是定向文献核验和实现溯源，不是系统综述，也不是外部算法复现报告。

## 1. 必须遵守的引用口径

每项方法按“原文做了什么→我们借鉴什么→实际代码如何做→目前验证到哪一步”入稿。相关论文不能替代本系统实测证据；调研、拟采用、工程实现和效果验证必须区分。用户提出的应用设想要保留提出过程，但已有区域生长、主动轮廓等原理不能包装成首次提出的新算法。“由中心向外扩大圆”不能直接命名为高斯算法。

我们需要分别识别照片范围、实体纸张范围、纸上手绘UI页面范围。纸张与桌面分开，不代表手绘UI页面已被找到；纸内页面内外都可能同色。“最外侧线”也可能是纸边、桌纹或阴影。

## 2. 页面层级、全局与局部规划

### R1：MM-WebAgent（已借鉴设计原则，未复现整套系统）

Yan Li, Zezi Zeng, Yifan Yang, Yuqing Yang, Ning Liao, Weiwei Guo, Lili Qiu, Mingxi Cheng, Qi Dai, Zhendong Wang, Zhengyuan Yang, Xue Yang, Ji Li, Lijuan Wang, Chong Luo. **MM-WebAgent: A Hierarchical Multimodal Web Agent for Webpage Generation**. arXiv:2604.15309, 2026. DOI: 10.48550/arXiv.2604.15309。

- [论文与版本信息](https://arxiv.org/abs/2604.15309)
- [官方方法页](https://microsoft.github.io/MM-WebAgent/)，重点为 Hierarchical Planning and Generation。
- 原文依据：全局层安排页面区段层级、顺序与空间组织；局部层规划多模态元素，并有局部、上下文和全局反思。
- 我们借鉴：先确定全局组织，再处理局部元素，避免只优化两两控件关系而忽略全页。
- 我们自己的任务化设计：照片坐标→手绘页面边界→标准手机/电脑画布→局部区域→元素；来源ID、父角色合法性、关系引文校验、局部/全局坐标编译和受控组件生成。这些具体机制不能全部归到MM-WebAgent，也不能声称其原文已解决手绘纸边识别。
- 实现溯源：`src/utils/hierarchy_contract.py`、`src/utils/global_spatial_contract.py`；轮05、06、24优化卡。轮24空间参照候选失败，页面边界仍不可靠；不能写成完整映射方案已成功。
- 入稿位置建议：现有4.3.1引用[26]保持并核对参考文献编号；6.7.5区分设计假设与失败结果。

父子语义声明、浏览器DOM嵌套、矩形几何包含、用户感知正确归属是四类证据，不能互相代替。轮18只证明同一新上游下有效关系保留改善，未证明视觉布局或操作体验改善。

## 3. 由内向外找边界：方法依据与未采用状态

### R2：Seeded Region Growing（调研，未接入）

Rolf Adams; Leanne Bischof. **Seeded Region Growing**. IEEE Transactions on Pattern Analysis and Machine Intelligence, 16(6):641–647, 1994. DOI: 10.1109/34.295913。

[原论文全文](https://www.csd.uoc.gr/~hy471/papers/SRG.pdf)。已核对全文的种子与相似邻域生长思路。可为“从纸面内部种子出发，按颜色/亮度相似性扩展纸面区域”提供依据。它不是固定半径圆周扫描，种子位置、阴影和背景相似色会影响结果；它也不能独自区分同色纸面上的UI页面内外。

### R3：Snakes（基础背景，未接入）

Michael Kass; Andrew Witkin; Demetri Terzopoulos. **Snakes: Active Contour Models**. International Journal of Computer Vision, 1(4):321–331, 1988. DOI: 10.1007/BF00133570。

[作者托管原文](https://web.cs.ucla.edu/~dt/papers/ijcv88/ijcv88.pdf)。作为可变形轮廓、内部平滑约束与图像外力的基础出处；不能将经典Snakes本身等同于增加膨胀力的Balloon扩展。本次获取的PDF缺少可解析文本，不冒称逐式复核。

### R4：Balloon（与用户膨胀设想最直接相关，未接入）

Laurent D. Cohen. **On Active Contour Models and Balloons**. CVGIP: Image Understanding, 53(2):211–218, 1991. DOI: 10.1016/1049-9660(91)90028-N。

[出版方记录与摘要](https://www.sciencedirect.com/science/article/pii/104996609190028N)。本次核对范围为出版记录与摘要；全文获取受限，不写成完整复现或全文公式审计。

原理对应：给可变形轮廓加入膨胀力，使其向边界运动；比“不断增大刚性圆”更接近实际边界形状。弱边缘可能被穿越，内部控件线也可能干扰停止条件；这项研究不保证能辨认我们任务中的最外层UI页面。高斯平滑、颜色高斯分布与轮廓膨胀是不同概念，不能混称。

### R5：Chan–Vese（区域统计依据，未接入）

Tony F. Chan; Luminita A. Vese. **Active Contours Without Edges**. IEEE Transactions on Image Processing, 10(2):266–277, 2001. DOI: 10.1109/83.902291。

[作者托管2001年期刊全文](https://www.math.ucla.edu/~lvese/PAPERS/IEEEIP2001.pdf)。已核对摘要及模型说明：以轮廓内外区域拟合和正则化驱动演化，不单靠梯度边缘停止。可作为纸面与背景统计分割的候选依据，不能保证解决同色纸内的UI页面边界。不要把1999年会议版SS99.pdf当作2001年期刊全文。

### R6：彩色/向量图像扩展（补充依据，未接入）

Tony F. Chan; B. Yezrielev Sandberg; Luminita A. Vese. **Active Contours without Edges for Vector-Valued Images**. Journal of Visual Communication and Image Representation, 11:130–141, 2000. DOI: 10.1006/jvci.1999.0442。

[作者托管全文](https://www.math.ucla.edu/~lvese/PAPERS/JVCIR2000.pdf)。对应多通道图像的区域统计建模；用于说明颜色信息有既有理论基础，不得据此声称我们的颜色纸面模块已经实现。

### R7：GrabCut（备选分割路线，未采用）

Carsten Rother; Vladimir Kolmogorov; Andrew Blake. **GrabCut: Interactive Foreground Extraction using Iterated Graph Cuts**. SIGGRAPH 2004。

[作者机构原论文](https://www.microsoft.com/en-us/research/wp-content/uploads/2004/08/siggraph04-grabcut.pdf)。已查询原论文入口和方法摘要，全文抓取不稳定，不冒称完整复核。矩形/交互初始化、外观模型和图割是另一条前景分割路线；它不是由中心向外膨胀。当前没有采用、没有新增交互标注或依赖安装。

## 4. 第25轮真正使用的算法：LSD线段检测

### R8：LSD（实际调用OpenCV实现，并非复现论文代码）

Rafael Grompone von Gioi; Jérémie Jakubowicz; Jean-Michel Morel; Gregory Randall. **LSD: a Line Segment Detector**. Image Processing On Line, 2:35–55, 2012. DOI: 10.5201/ipol.2012.gjmr-lsd。

- [原论文全文](https://www.ipol.im/pub/art/2012/gjmr-lsd/article.pdf)
- [期刊项目与代码记录](https://www.ipol.im/pub/art/2012/gjmr-lsd/)
- [实际调用接口官方文档](https://docs.opencv.org/4.10.0/db/d73/classcv_1_1LineSegmentDetector.html)

原文描述线段支持区域与误检控制。我们的实现`src/utils/page_line_boundary.py::detect_line_candidates`调用`cv2.createLineSegmentDetector(cv2.LSD_REFINE_STD).detect(gray)`，再按长度、方向筛选和去近邻候选，给线段编号；模型选边后由代码求交点并校验。论文算法、OpenCV实现和我们附加规则应分别交代；检测到线不代表知道线的语义身份。

轮25保留48条候选，选边混淆纸边、桌纹和UI页面边；实际右侧斜边line_44被选为bottom，交点越界而拒绝。自由边界组的坐标单位也不合约。两组均未通过页面边界子目标，不填页面功能分。这一轮没有使用区域生长、Snakes、Balloon、Chan–Vese或GrabCut，也不是Hough线检测。参考轮25卡及原包SHA256 `1b15aa333fc9e077ad1dc967f6b29df12a1e19d748d123249910a5f27a25b9fb`。
