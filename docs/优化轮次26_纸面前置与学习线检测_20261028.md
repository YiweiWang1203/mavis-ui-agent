# 轮26：可见纸面前置与DeepLSD检测验证

1. 用户失败：电脑草图页面外框未可靠定位，轮25线段选边混淆纸边和桌纹。用户同意先看可靠纸面范围内，更强线检测是否改善手绘页四边检出。原图左右纸边不全，因此不可预设完整纸张已定位。
2. 原因：有线不等于正确页面身份，现有最大四边形不区分纸与UI。Ubuntu已有torch/cv2/omegaconf/scipy，没有deeplsd/pytlsd/SAM2/SAM3。先读官方推理代码与依赖，不装训练依赖，不以安装成功当效果。
3. 假设：自动定位可见中性纸面以减少桌面干扰，在相同纸面图上用DeepLSD补强线几何证据，可以改善真实手绘UI四边的检出完整度。若纸面裁断UI或正确四边仍缺失则不支持假设；四边检出但选错需另定位语义选择。
4. 方案：复读空间层级与边界溯源、2010年后技术补充；采用CVPR2023 DeepLSD官方推理模型、MegaDepth通用权重（不调本例训练参数），与现有OpenCV LSD比较。独立目录system-site-packages venv仅补推理需要包，不升级原UV环境，不跑全量requirements。无Ceres线精修，不是完整论文复现。纸面前置暂用Lab色度Otsu的最大连通中性区域，闭运算5×5/填孔/边距8px，面积限制10%—98%；明确白/中性纸假设，非SAM、非全局可靠定位器，不把照片中心当种子或人手填边界。

固定002原图SHA256 8f4aec60993cfc8ce7aad9eeb3fd2edc1329a35d7efcaf514089cc8a211988a8。先保存自动纸面mask及叠图人工审查，若不可靠不得将检测对照解释为“可靠纸面之后”的成功。对照保存全照片/同一纸面包围裁图×OpenCV LSD/DeepLSD四组（前置裁图与检测器两因素分别比较）；纸面裁图不涂白内部像素，保留裁图偏移，线端点映射回原图。原始线全部保存，不用原图真值筛候选。主要对照是同纸面内两检测器，全照片组用于诊断背景影响，不揉成单机制效果。

主指标：人工审查实际UI外框四侧检出数/4、是否有整体完整页面候选/1、纸面处理是否截失UI/1；没有用户确认边界GT不编IoU/像素准确率，候选数和长线数仅诊断。每侧需检查线是否贴合真实手绘边而非纸/桌/内部框，保留未决；同一实施者审查不是独立人工。若用近似直线量化曲边覆盖，参考标注另存且不输入检测器，并说明近似误差。暂无标准化跨例准确率。

预算：0个LLM调用、同一模型最多2次图像前向（全图/纸面），各一次无模型重试；下载/环境准备各有超时，不无限重试。整体运行推理上限600秒，安装600秒，下载90秒；记录源码commit、权重hash、依赖、GPU与耗时。模型下载失败单独保留，不换另一权重挑结果。与旧轮不同，这是检测边界子实验，无HTML、不跑主输入/点击分数。冻结ASR/图不重跑、不改旧HTML，GT不进生成，冻结论文不动。

5. 实施：`src/utils/paper_line_probe.py`和`scripts/run_paper_line_probe.py`，从冻结case图重新执行。启动后记录独立检出、PID、state/results.zip；纸面边界未审查时状态必须pending_review。
6. 决定：若前置可靠且检测有改善，再固定同一选择器测闭合UI页面身份；若前置不可靠先解决纸面；若原LSD已检出四边而误选，则线检测强弱不是当前首要原因，不继续盲换ScaleLSD。独立导师SKILL未找到，遵循user-centered-optimization。
