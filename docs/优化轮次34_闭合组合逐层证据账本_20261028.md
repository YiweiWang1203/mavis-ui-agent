# 轮34：闭合组合逐层证据账本

1. 用户失败：轮33补入35条唯一原始短线后，候选仍全是局部区域，整页候选0/1；两次语义请求均超时。保留失败，不重试。
2. 定位缺口：已有记录只给闭合首拒汇总；没有全部角色组合的交点、图外量、侧支持与角点外延，尚不能确定真框在哪一层失效。不先归因单阈值。
3. 目标后复读《手绘页面定位与空间理解_学术路线复核》P0及L-CNN/HAWP的线—交点表示、LETR对中间启发损失的提醒。借鉴可追溯表示，不复现其检测器。独立导师SKILL未找到，遵循user-centered-optimization。
4. 假设：在不改候选行为的前提下，把同一次新LSD的每个闭合组合写成可追溯账本，可区分观察支持不足、拟合交点图外和内部区域身份问题，为下一机制提供证据。
5. 固定方案：冻结002原图/ASR及轮33几何。重新执行一次LSD、空间48锚线、原聚合和端点补招；每组枚举所有组合，记录来源ID、交点、图外距离、凸性/顺序/面积、每侧观察支持及外延、正式首拒。用原compile_boundary/validate_fragment_sides原判据；实际接受/首拒计数及最终去重候选必须与正式closed_candidates一致，否则诊断失败。没有把不合格组合编译为页面。近失列表仅诊断，不可交模型充当合法候选。
6. 预算与验收：0 LLM、0深网前向、无安装、原UV，最多120秒本地几何执行。两组均逐组合账本覆盖100%，接受/首拒计数和正式输出一致、全部来源可追溯；这是工程诊断指标，不是页面定位准确率。新日志不能冒称历史实时日志。当前不优化图框阈值、不喂GT、不填四角，不生成HTML或功能分。13例仍开发材料，同一实施者复核。待看账本后再决定下一功能机制，不将本轮归为生成改善。
