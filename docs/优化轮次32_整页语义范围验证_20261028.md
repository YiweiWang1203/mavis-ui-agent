# 轮32：整页语义范围验证

1. 用户失败：轮31生成的两个候选都是内部左栏框，模型仍选其一作为整页，诊断映射裁掉主聊天区。正确页面候选缺失与错误选择是两个已知问题，本轮只处理第二个；不将拒绝假页面当完整生成恢复。
2. 原因定位：原选择调用已有outer page而非sidebar的文字要求，但输出只给ID，无逐候选范围判别。实际被误选框上边在内部历史行附近，右边为栏间分隔，主聊天内容在外（实施者目检非GT）。正确外框仍未进入候选，不能靠语义验证创造它。
3. 目标后复读《手绘页面定位与空间理解_学术路线复核》Magic Layouts的UI整体结构思路与Sketch2Code对理解/澄清失败的反证：不能相信一句提示或增加Agent必然有效。本轮是同次调用显式范围判断与代码一致性验证，不称论文复现；独立导师SKILL未找到，遵循user-centered-optimization。
4. 假设：要求每个候选说明是整页/内部区域/纸背景/不确定并列出框外主要UI，再由代码拒绝范围矛盾，可减少局部框误当整页；自报证据仍可能幻觉，必须看原图核实。

## 固定机制、对照与验收

同一次新LSD、固定spatial_v1来源选择、原碎线聚合/闭合规则，生成一份shared_identity_candidates.json。基线与候选共用完全相同候选几何、原图和原口述，基线原ID选择，候选同次模型输出新增assessments。代码严格每ID一条、不漏不造；选中项必须whole_ui_page且框外UI列表为空，否则失败不默默改成另一个框。所有原始响应保留。显式null允许，但不得算整页定位成功。

主指标本例假页面接受数/被选择页面数、是否在无整页候选时正确未决；同时固定报告真实外框候选可用0/1、最终整页定位是否仍0/1。分母0记不可评，不因候选组没选就写误选率0%。反证：候选仍接受局部框、未完整评估或列出的可见内容与图不符，均失败。全量两候选目检非独立人工；无GT不用IoU/召回。若本轮出现新的几何候选，先核验共享与身份后再按实际候选集合审查，不凭历史预设。

预算：各最多一次Qwen/Qwen3-VL-8B-Instruct，8192输出/600秒/零自动重试，合计最多2物理调用，0深网，无新依赖，原UV。候选额外schema/证据token成本单报，不称单纯提示句消融或已减少模型幻觉。两组空集均跳过。无HTML，错误映射图仅诊断，不修旧结果。软件检查覆盖范围矛盾拒绝、框外证据阻止接受、完整性与未决，非视觉准确率。

这是对已知负例的开发验证：只能支持拒绝误选的子目标。下一轮仍需定位真边界支持的来源/聚合/首拒，不能对本轮成功的未决宣布整体问题解决。原始轮31失败保留、不改阈值网格重试。版本/PID/路径与结果另记。
