# 轮次10：关系源证据局部隔离

1. 用户失败：两个口述/视觉名称不一致的关系导致整页没有产物。轮09API正常，但地点关系缺字面锚点，严格校验使全部生成终止。
2. 原因：验证要求本身没有证明需要放宽，问题是源证据不充分与全局身份/结构矛盾同样以整页异常处理，传播范围过大。现有五条预定关系之外的地点归属仍待确认，不得删除这个问题。
3. 假设：只对关系的源引文/名称锚点错误做局部隔离，保留其原因及原提议，其他可验证关系继续布局与生成；能够减少无必要的整页中断，又不把别名或无依据关系自动变真。
4. 方案前依据：已复读链路诊断与Agent架构调研中有界失败处理、身份不变量和独立执行验证建议，借鉴WebGen-Agent有界错误处理思路，不称复现。单机制为源证据错误作用域隔离：旧strict模式保留；新hierarchy_partial_evidence_v1只将引文不存在/缺少子名称/缺少父描述这三类错误记入unresolved_edges并跳过该关系，不改元素、不改原标签、不下调证据标准。身份重复、无效节点/容器、父冲突和循环仍全局失败，避免任意保留一个父节点。缺少relationships数组仍失败。结构元数据与运行摘要显式标记未决数量，HTML生成不等于整体达标。
5. 固定目标与预算：两组均controlled_components_v1/source_alignment_v1，比较严格hierarchy_evidence_v1与局部隔离hierarchy_partial_evidence_v1，系统提示相同，仅校验策略不同，上游仍独立采样，不能做严格因果归因。每组2次模型请求，共最多4次；同Qwen/Qwen3-VL-8B-Instruct、8192输出token/阶段、600秒、零自动重试。目标：遇到源证据局部不足时，候选可生成并逐条报告未决，五条预定结构及实际包含5/5、输入1/1、五按钮标签反馈5/5、精确尺寸逐项一致、0越界、身份唯一、登录横向；全局结构矛盾不能被隔离吞掉。未决关系不是正确关系，必须另报，不能说全部页面需求满足。
6. 决策：若两组没有触发源错误，只能记生成观察，不能声称隔离提高完成率。若仍出现全局失败先定位，不能扩大预算重试。若预定子集通过但地点归属仍未决，下一轮处理多源名称对齐或请用户确认，而非扩大回归掩盖局部错误。继续保留所有首次失败。仅008开发例，未重新执行ASR/选帧、未修改旧HTML。
