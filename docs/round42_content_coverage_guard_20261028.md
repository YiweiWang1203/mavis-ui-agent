# 轮42：页面内容落框反证（实施前冻结）

1. 用户失败：第41轮基线选中框漏底部导航，候选盲报范围偏宽而未决，均未正确输出整页。用户最新明确：若属于页面的元素在外框之外，应作为反证；重点是页面—区域—元素归属，不再追求唯一算法找完美闭合框。原41 ZIP和44内部引用已核验，本次SSH确认结束、哈希一致，无运行任务。
2. 原因：原选择只有几何线支持与自由ID判断，没有“页面内容不得落在所选页面外”的可执行契约。41说明模型可描述主要内容却报不准外框范围；不能证明点定位一定更准。目标后复读架构调研、学术路线复核及六步技能。借鉴Magic Layouts（Manandhar/Jin/Collomosse, CVPR2021, https://arxiv.org/abs/2106.07615）的结构约束思想，但其移动UI空间共现先验不是本轮算法；SoM（Yang等2023, https://arxiv.org/abs/2310.11441）支持视觉引用可审计的研究思路，本轮不运行SAM/SoM，也不声称复现。轮41卡所列文本顺序/多图位置偏差只提供诊断背景，不证明本轮效果。独立同名导师SKILL仍未找到。
3. 假设：独立从完整原图观察属于同一UI页面的可见主要区域，各取一个明确位于区域内部的点，再由代码检验选中quad是否包含这些点，能拦截“线框闭合却漏内容”的错误。它是反证保护，不是完整页面识别器；若漏观察、点坐标错、把纸背/标注当UI，保护可能漏报或误拒，均保留实测。
4. 固定方案：同一新全帧/新LSD/冻结有界两跳几何。基线原简洁ID选择一次；独立内容观察一次，只见原图、原口述和image_size，无候选编号/接触图/基线结果。契约只有regions数组和uncertain布尔；每项id/name/point=[x/width,y/height]/visual_evidence，ID唯一、点必须0—1，数组非空。只报有视觉证据且可归属本UI的区域，不从用户描述补造不可见内容；无把握设uncertain=true，空集或uncertain不作通过。没有预填导航或案例标签。
   代码对所有已观测点与每个已有quad四侧计算带符号距离，记录inside及违反的边。逐点位于凸四边形内/边上才相容，原几何规则不放宽、不延长角点。点是内容区域内部锚点，不代表整区域边缘被完整包含，不称覆盖率。基线原选中框若排除任何点则候选组未决；全部点通过也只记“未被当前内容证据反驳”，不是整页身份已证实。不自动改选其他框，不按已知正确ID调整顺序，不投票。保存所有候选相容表及原始证据，但不将表当真值。
   基线与候选共享本轮新选择；候选比基线多一观察调用，有效成本1与2，物理2而非3。最多2物理Qwen请求，每次8192/600秒/零重试，温度0，0深网/安装。空候选双方直接未决。并非等调用数消融；不用旧轮响应。
   主验收：本轮错误基线选择若仍漏UI，拦截该漏内容框1/1，错误放行0/1；若新基线选对，不构造错误输入，主触发条件未出现即不可评。副指标分别报最终整页正确各1/1目标、未决、API/契约失败、观察真实区域数/提议数、全部点定位手审及误拒。拒绝错误不是已选对；最终未决仍未完成用户任务。真整页候选是否存在各1/1另报。无GT不编IoU/精确覆盖率，边界子实验无HTML/浏览器功能分。
5. 实施验证：保存旧源码、明确提交文件、原UV独立检出、真实新输入/请求响应/点叠图/逐侧距离/哈希齐存。原图ASR冻结，不重选帧、不修旧HTML、不把GT/手工点给生成器；用户截图只供问题定位。所有点来自本次新模型观察，同实施者目检非独立人工，13例仍开发，论文冻结分不变。
6. 下一轮：结果后决定，不能将否决保护当层级已解决。若保护有证据，再设计页面—区域—元素的带来源层级表示及区域尺度验证；若点观察失败先定位，不无限叠提示/降阈值。各边观测距离是可解释证据，不是校准概率；纸背透线成因仍未证实。

用户实施中补充已纳入同一机制：不只拒绝，需指明外侧内容在哪条边之外、下一步朝哪边找。代码从原四侧的带符号点距离生成correction_hints，记录每侧反例区域ID、外法线方向和“保持该侧方向平行移动以包含这些观测点”的最小像素位移下界。该值不是实际页面边界位置，不增加补角/阈值、不编辑quad、不自动改选。倾斜侧使用外法线而非硬编码图像上下；相邻侧可能共同违规，全部保留。真实语义/坐标错误会使指示错误，需同样验收。不把诊断建议冒称页面修复完成。


用户启动前再补充：不只报告漏，也要报告多包的部分。最终冻结契约每个区域增加membership=page_ui|outside_page；后者只能来自明确处于手绘UI外的可见证据，不把纸张颜色或留白自动判作页面外。UI点在quad外报告缺失及向外搜索方向；outside_page点在quad内报告额外包含及到四侧的距离、各侧向内搜索方向。最近边只是几何建议，无法单独证明该侧应改；所有建议保留，不擅自取最近边修改。至少一个page_ui点且全部成员条件相容、uncertain=false才可“未反驳”；空证据不通过。主反例拦截仍是本轮已知漏导航，额外报告全部多包诊断与真假，若未观察到明确多包反例则不编造其准确率。本轮不自动补齐/收缩四边或修复HTML；这些方向证据供后续联合层级规划使用。代码首版bda3d90提交后用户补充发生在启动前，最终运行版本另记，无中途改运行目录。
