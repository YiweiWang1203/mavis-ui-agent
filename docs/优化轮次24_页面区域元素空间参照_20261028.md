# 轮24：页面—区域—元素空间参照（实施前固定）

1. 用户失败：002电脑聊天页整体位置混乱；23轮只修主输入，不是整体布局成功。原图406×720竖幅照片中，手绘页面为中下部横向矩形，桌面和纸边不是UI边界。旧视觉归一化框部分不在实际手绘页面内（人工查看effective_image），没有独立页面边界记录，10对象均无父关系，个人头像与上传部分重叠。尚不能把所有错误归因比例映射。
2. 原因：当前build_structure直接用视觉归一化框乘1440×900；无法区分照片坐标与手绘页面坐标。旧视觉坐标本身也有定位误差，单纯裁框换算无法纠正。缺全局区域结构已确认；各项视觉定位需重新观察验证。
3. 假设：在同一新上游对象清单之后，用同一有效图像进行一次页面边界→区域划分→既有对象重新定位的空间规划，代码显式编译图像、页面、区域三套参照，可改善区域错属、比例失真、重叠。它是整体空间参照机制及额外视觉观察，不把收益拆归某一提示句或单纯父子字段。
4. 目标之后复读既有研究，并重新实读MM-WebAgent官方Method https://microsoft.github.io/MM-WebAgent/ ：借鉴先全局section hierarchy/ordering/spatial organization，再局部规划；不是复现算法。本实现是自研轴对齐页面映射，不含透视校正、不恢复漏检对象。独立导师SKILL未找到，按user-centered-optimization执行。
5. 固定方案：共享本轮新视觉/架构两次请求和既有节点，基线原结构/坐标，候选新增一次原图空间规划。模型只能声明页面边界、原文支持的区域及已有ID位置；不改已有类型/文字/动作、不增语义控件。区域先父后子、精确原文引文、端点唯一/完备、范围合法；不默默夹框、不吞遗漏。区域标签为元数据，不往页面添加标题文字。代码从image bbox算page bbox与parent-local bbox，最后一次转换全局像素，保存旧坐标及变更。渲染器沿用受控组件器；语义父关系记录与几何包含独立检查，DOM仍扁平绝对坐标，不宣称DOM嵌套。
