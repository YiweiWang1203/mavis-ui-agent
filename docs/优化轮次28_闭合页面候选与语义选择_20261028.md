# 轮28：闭合页面候选与语义选择

1. 用户失败：页面边界未可靠定位，后续区域比例无可信坐标参照。轮27四组叠图均可辨UI四侧线段，但未得到自动闭合页面，纸面裁图仍混入底桌。不能先称线检测不足。
2. 定位：轮25模型把纸边/木纹/页面右斜边选成错误四侧，交点越界；轮27证明至少存在边线证据，未证明检测器优劣。已证实“有线不等于UI身份”，待检验的是组合选择职责，而非安装更强模型。
3. 假设：代码先形成有来源且在图内、凸、各侧有足够投影支持的闭合四边形，再由视觉模型只选候选ID或未决，可减少自由选四线的角色混乱与无效闭合；若候选遗漏真实页或选择内部/纸框则假设不成立。
4. 目标确定后复读《空间层级与边界定位_参考依据及实现溯源》《页面边界定位_2010年后技术补充》：采用既有LSD/OpenCV线证据；DeepLSD研究支持几何检测而非页面身份，MM-WebAgent只提供全局/局部分工思路。此处闭合枚举/投影校验是我们的工程设计，不声称复现某篇学习轮廓或SAM，不把纸面可靠性预设为真。

固定方案：002同一冻结原图8f4aec60993cfc8ce7aad9eeb3fd2edc1329a35d7efcaf514089cc8a211988a8、原口述/用户提示、原UV Python；重新从原图执行OpenCV LSD和既有detect_line_candidates（长度>=min图边12%，近横/竖20度、每方向24条、近中点5px去重）。同一线集供两组：基线自由选四条ID，候选先枚举横/竖线对（最多C24,2²=76176组合），沿用compile_boundary图内/凸/次序/最小面积2%/观察长度校验，再要求每侧投影与目标边重叠比例>=60%。按面积×最弱侧支持排序，四角最大距离<短图边1.2%去近重复，最多16候选。几何排名不等于语义答案。候选组原图+全部16以内候选接触图+来源ID/面积/支持，模型只能选完整候选ID或未决，不改坐标/补边；不使用人工四边或GT。没有候选仍允许模型未决，不自动降低阈值。

两组各一次Qwen/Qwen3-VL-8B-Instruct，temperature0、每次8192输出token、600秒、零重试，整轮最多2物理调用（不超过既有3调用上限），无DeepLSD前向、无下载安装。基线与候选调用数相同但图/文字token不同，成本另报，不称完全同资源；对照是几何候选及选择接口整体，不归因于某一句提示。顺序固定基线后候选，不挑最佳。

预定验收：候选包含可辨真实UI外框数/至少1（实施者逐图审查，未确认GT不算IoU）；候选封闭且全部角点图内比例、未知来源ID0；最终选择正确手绘UI外框1/1、四侧有原始支持4/4、纸桌误选0、明显内部控件框误选0、UI内容明显裁失0；未决/失败如实记，不用几何有效代替语义正确。边线弯曲/透视、照片出界和候选cap漏失另报。若无正确候选，先定位召回/投影阈值/排序，不让模型自由补造。原始图、同一线集、全部候选及裁减前计数、模型请求响应、选中ID/映射叠图、哈希、环境/耗时/token完整保存。无用户确认GT，无独立人工复核；这是开发单例边界子实验，无HTML、无交互/整页生成收益。
