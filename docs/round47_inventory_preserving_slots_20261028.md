# 轮47：保全对象骨架的语义槽位编排

3. 用户价值目标：保留全部源对象及主要视觉比例，修正口述支持的归属/顺序，避免新增遮挡。假设：代码保全原几何骨架，模型仅提供小范围来源明确的分组和槽位顺序，再在已有槽位间交换对象，可避免漏对象和任意等分，同时改善层级和局部组织。

目标确定后复读架构调研20261027：MM-WebAgent全局/局部职责、证据几何与渲染几何分离；学术路线复核20261028：Magic Layouts移动结构先验不能直接当桌面模板、Sketch2Code定位仍可能失败。本机制为工程改造，不是复现或新颖性主张。参考：https://microsoft.github.io/MM-WebAgent/；Manandhar/Jin/Collomosse,CVPR2021, https://arxiv.org/abs/2106.07615；Li/Zhang/Yang,NAACL2025, https://aclanthology.org/2025.naacl-long.198/ 。已有材料只支撑职责借鉴，不证明本机制有效。

4. 固定机制：原state完整深拷贝，模型只返回groups:[{id,children,axis,quote}]。id为已有合法容器，或layout_前缀不可见布局组；不新造UI对象。children只引用已有对象、不允许重复归属/自包含/未知ID，axis为row/column/null。每组引用唯一原文子串，字面通过仍须手审语义。未提及对象一律保留原bbox/类型/文字/动作，不把未分组当覆盖成功。合法父关系和循环校验保持。

row/column仅允许原孩子在相应行/列有共同垂直/水平交叠区间，避免把二维卡片当一行重排；不共线则整个提议拒绝，不吞坏组或自动改轴。按原bbox沿轴排序形成原槽位，模型只决定对象占哪个现成槽位；无weight字段、不新增尺寸模板。axis=null只建立成员关系。已有真实容器自底向上扩展至已接受孩子bbox并集，不缩小、不补未知边；保留旧bbox及变化原因。匿名组只记录，不成为检测对象或语义父节点。若因交换槽位发生遮挡/比例不合理仍判失败，几何观测非GT。

同次新视觉+架构2调用产生基线，额外一次只读原图/原口述/不可改对象与bbox的分组调用，共至多3物理请求。Qwen/Qwen3-VL-8B-Instruct、8192/600秒/零重试，无Coder/额外关系/输入调用、深网、安装。有效基线2/候选3，非等成本消融；输入冻结008完整原帧及ASR，不读旧响应、GT或旧HTML。

主验收：全部新源对象保留N/N且类型文字动作不变；导航顺序及卡片/导航归属按原图/口述检查；五主要区域内容5/5、比例不因全局等分失真。原定义五条结构及已有容器矩形包含各按5报告，缺父不改分母。容器新增覆盖和所有原本/新增跨区冲突单列。输入1/1、固定五点击反馈5/5（主界面/回主界面异名须唯一原图状态核对后实际点击）、DOM尺寸N/N、0越界/重复、无新增真实遮挡；原HTML不改，实操截图、HTTP200后预览。布局组引文存在不当语义全通过，未触发或空组不能称改善。
