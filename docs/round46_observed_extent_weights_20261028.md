# 轮46：观测范围驱动布局权重

状态：方案冻结，实施前；窗口43—52第4轮。导师技能为骆昱宇教授Supervisor-Skills的idea-evaluator及fatal-flaws参考；执行另遵守项目六步技能。

1. 用户失败与定位：轮45新HTML区域全等分，地图高度422变162.4、头像49变162.4、导航41变162.4；原始规划每层weight全部1，编译器忠实等分。卡片row错误及缺card/nav对象也真实存在，本轮不掩盖。原包及105哈希已验收，SSH本次核对终态未变。
2. 目标：减少相对树在目标画布内编排时引入的比例失真，保留有依据的顺序；不声称单机制解决全部层级。
3. 研究复读：目标后复读架构调研20261027中证据几何/渲染几何分离、MM-WebAgent全局到局部分工，以及学术路线复核中Magic Layouts结构先验与桌面适用限制。借鉴的是职责分离，区间并集范围计算是本项目工程设计，非论文复现或新颖性主张。MM-WebAgent官方 https://microsoft.github.io/MM-WebAgent/；Magic Layouts, Manandhar/Jin/Collomosse,CVPR2021 https://arxiv.org/abs/2106.07615 。已有资料不足证明观测框准确，不能把其当GT。
4. 假设与固定方案：每个兄弟节点的权重由其所有原始对象bbox并集在父布局轴上的跨度确定，而非模型自由给数；相同新树、原始节点、原图/口述和渲染器对照原权重/观测权重。先完整校验原树，再计算来源ID、原bbox、跨度及归一权重；跨度非正、非有限、源bbox越界即拒绝，不回退等分或修改树。容器自身与孩子的证据并集均记账。只改变权重，不增删对象、父角色、轴、顺序、引文；缺失/错误分组继续报告。根画布仍原375×812或源设备画布，未修旧HTML。

实验一次新视觉+架构+相对规划，共最多3物理请求，各8192/600秒/零重试。共享3请求后分别编译model_weight与observed_extent，两组有效均3/独占0，不能算6；另保存原绝对坐标HTML作参考（有效2），不累加物理。同一原始规划及状态哈希必须相等，模型提示、输入和校验不改。只读本次新上游，不读旧响应/GT。原UV独立检出，无安装或深网。

主指标预登记：对每一布局分叉，比较新HTML兄弟沿轴尺寸比与其原观测跨度比的总变差距离(1/2绝对差和)，候选误差目标接近0、基线大于0才算机制触发；该量是观测一致性，不是草图GT精度。必须截图审查地图仍为主体、头像/导航不被异常放大，按原图比例形态手审，不以公式通过代替可用性。若源观测错误或编译范围错误，比例一致仍判未达标；无触发不称提升。

退化约束：主输入1/1、既定五标签反馈5/5、尺寸全部吻合、0越界/唯一身份，无新增矩形交叠及实际遮挡。五主区域内容保留5/5，结构及已有容器矩形包含各仍固定5条分母；匿名组不代替父关系。卡片上下布局/登录类型/容器遗漏另列，不能用局部比例收益称完整达标。HTML实操截图、哈希不变、HTTP200后提供预览。008开发例，同实施者非独立人工，无ASR/选帧重跑。

导师审查：轮45模型权重充分性已被否定，维持Reject and Pivot，不为其打分或找阈值防御。本轮把权重决策交给可追溯观测，是不同的可证伪机制；Accept with Revisions仅允许一次小规模验证，工程应用而非创新论文。Higher6（机制依据，未实证），Faster5/Cheaper5（同3调用），Stronger5（观测误差仍会传递），Broader5（单手机开发例）。若观测一致但肉眼无收益或退化，不继续调比例救本例，回到上游身份/观测可信度。

5. 实施验证：待限定提交、两端工程检查、独立UV真实生成及原包/浏览器验收。
6. 决定：有局部比例收益才保留可选机制，整体失败仍报告；下一轮按剩余来源/区域类型失败定位，不用本轮权重机制掩盖缺容器或卡片轴错误。
