# 下一轮：层级与空间契约

状态：方案已记录，尚未实施功能修复。依据用户对008原始生成页面的六条浏览器反馈、真实21事件埋点和零API隔离诊断。研究材料为定向查阅，不称系统综述。

## 用户目标与原因

用户能在草图对应区域找到控件，区域内的元素留在该区域，搜索框可以输入。基线16→32发生在ID融合；32元素布局后18框越界。隔离16元素仍有5框越界，证明身份修正并不足够。

已有parent_id和children_ids，但本例各阶段均为空；布局算法也未按父子区分。架构提示中所有框必须互斥的规则与正常容器包含子元素矛盾，需与代码契约一并修正。不能只添加一句提示词继续沿用旧碰撞算法。

## 目标架构

输入证据→稳定元素身份及来源→页面/区域/控件关系树→层级约束布局→HTML生成→结构与浏览器验收。仍保存原图全局坐标，另存渲染坐标与转换；不混淆局部、全局像素或归一化坐标。

身份匹配保留视觉ID与模型语义别名，显式引用来源。对应时综合来源、类型与几何，使用一对一约束；文本相同不是充分条件，重复列表项不得随意合并。低置信对应标记未决，不以缺失名义静默补入所有对象。口述真正新增的元素保留独立来源。

层级关系优先使用明确口述与可信的视觉包含证据。几何包含只是候选，不可认为所有包围框都是容器，亦不可把图像上的覆盖按钮随意当图像子控件。记录关系来源、冲突及置信度；校验父节点存在、单父、无环和children反向一致。

布局按区域递归处理，只在同一父节点下判断并排、上下与碰撞。容器和子元素允许包含，祖先后代不得被强制排斥。同级合理覆盖需有明确语义，否则校验并报告。不要把所有块仅凭纵向重叠连成同一行。优先保持原始相对位置，做必要的局部尺寸调整；空间不足标记不可满足或按已定规则允许滚动，不生成1像素条、不藏内容伪装成功。

HTML阶段采用一致的层级坐标约定。若使用嵌套DOM，子元素CSS坐标必须转换为父容器局部坐标；若保留全局布局也必须显式验证包含关系，不能把全局坐标直接写入嵌套子节点。父子契约、实际DOM关系与浏览器位置分别检查。

## 分步实施与归因

A：身份/来源对齐，单独提交和新生成验证。检验重复补入减少且口述新增、合法重复项未被删除。

B：在A上启用层级提取、传递、验证与层级布局。这是完整机制，需要协调结构输出契约和布局代码；不是纯提示词实验。新生成验证，并与A对照，定位层级机制额外收益。A完成不视为用户本轮目标完成。

C：独立处理组件类型落实，统一search_bar/search_input/input等语义类型和原生控件生成约束，再在浏览器检查输入与反馈。不能把A/B页面变整齐当成C已通过。

先做通用最小复现和工程测试，保存旧源码、证据及差异；只对阶段目标修改代码，再推送并交付Ubuntu命令。均从案例输入重新生成，禁止改旧HTML作为结果。

## 验收设计

008开发诊断案例：导航容器含菜单/主界面/返回三项；选址卡片含现在/预约两项。先验收这五条原口述支持的关系，结构引用和浏览器实际位置分别计分，不把矩形包含自动当作语义包含。评测清单不喂给生成器，不按案例ID硬编码。

- 身份：同一来源对象不重复渲染；地点一按用户原设计出现一次；独立列表重复项及口述新增需求不得被误删。
- 空间：五条包含关系分别通过，所有输出框在声明画布/滚动内容边界内；登录区域保留地图下方的横向关系，不被排成竖条。
- 视觉：用户反馈的区域边界应可辨；先核对其来自地图框还是容器，不把选中高亮线当页面设计，也不将div标签闭合当作视觉边框闭合。
- 操作：搜索框可聚焦、输入、保留文字；按钮按原需求提供相关反馈。每项独立报告。
- 退化：元素内容、手机/电脑要求和其他既有交互不退化。先008主例，再002电脑聊天与003表单等开发回归，随后扩展其余开发案例。

单次各版本仍用相同模型、冻结图片和转录、8192输出token/阶段、600秒、零自动重试。关系机制优先复用既有调用；如果必须增加调用，先更新资源方案，并用可比预算对照。正式对照重新运行基线与候选，不把保存响应重建当生成效果。真实结果回来后决定保留/修改，不预言提升百分点。

## 研究依据与采用边界

MM-WebAgent的全局布局规划与局部元素规划支持分层职责；不等于其代码能直接解决我们的草图父子关系：https://microsoft.github.io/MM-WebAgent/

WebGen-Agent借鉴执行、截图和GUI操作反馈，而非模型自行声称成功；有界反馈需要另行验证成本：https://arxiv.org/html/2509.22644v1

WebUIProof借鉴结构化需求配合可执行交互检查，渲染成功不能替代操作成功：https://arxiv.org/html/2610.02617v1

这些工作输入、任务、模型和预算不同；当前借鉴方法思想，未复现其系统，也不宣称多Agent或反馈循环能消除所有错误。
